Map file name structure

IGPSPORT devices identify a Mapsforge .map file by its 24-character name: country, region, date and a tile-based GEO code describing the covered area.

GEO code structure

12 Base36 chars · Web Mercator tiles at zoom 13 (N = 8192)

MIN_LON · western border

Base36(floor((MIN_LON + 180) / 360 × N))
Tile X of the minimum longitude

MAX_LAT · northern border

Base36(floor(mercatorY(MAX_LAT) × N))
Tile Y of the maximum latitude

LON_SPAN-1 · width

Base36(LON_END − LON_START)
LON_END = floor((MAX_LON + 180) / 360 × N)

LAT_SPAN-1 · height

Base36(LAT_END − LAT_START)
LAT_END = floor(mercatorY(MIN_LAT) × N)
Web Mercator projection
mercatorY = (1 − ln(tan(lat) + 1 / cos(lat)) / π) / 2
lat in radians: lat_rad = lat_deg × π / 180

Base36 reference

3 chars cover 0 – 46,655 (36³ − 1)
